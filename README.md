# PyreChat

Flutter client for PyreChat. This directory is the active app source; the
nested `pyrechat_flutter/` directory is an older copy.

## Development

Run `flutter pub get`, `flutter analyze`, and `flutter test` from this
directory. Android development builds use `flutter build apk --debug`.

## Mobile alpha

See [Mobile alpha delivery](docs/MOBILE_ALPHA.md) for GitHub Actions,
Android signing, iOS/TestFlight setup, and the current platform limits.
